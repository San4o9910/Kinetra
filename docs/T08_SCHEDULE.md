# T08 — расписание программы

T08 заменяет заглушку `/schedule` на рабочее расписание текущей и следующей недель. Экран и API
доступны только пользователю со статусом `active`; идентичность берётся из access JWT.

## API

### `GET /api/v1/program/schedule`

Защищённый endpoint возвращает компактные данные без video ID, object keys и подписанных S3 URL.
Ответ помечен `Cache-Control: no-store`.

```json
{
  "current_week": {
    "week_number": 1,
    "title": "Неделя 1",
    "days": [
      {
        "day_of_week": 1,
        "day_label": "Понедельник",
        "direction": "breathing",
        "icon": "🧘",
        "title": "Дыхательная практика",
        "description": "Настройка нервной системы, учимся дышать животом.",
        "duration_minutes": 25,
        "completed": false
      }
    ],
    "days_completed": 0,
    "total_days": 7
  },
  "next_week": {
    "week_number": 2,
    "title": "Неделя 2",
    "days": [],
    "days_completed": 0,
    "total_days": 7
  }
}
```

`current_week` вычисляется той же серверной логикой, что и главный экран: следующая неделя
становится текущей только после завершения всех семи разных дней предыдущей. `next_week` — ровно
следующий номер; на неделе 12 поле равно `null`. Статус каждого дня берётся из
`workout_completions` текущего JWT-пользователя.

Ошибки используют общий формат `{ "error": { "code", "message" } }`. Без действительного
access token endpoint отвечает `401 AUTHENTICATION_REQUIRED`.

## Каноническая неделя

Одинаковая структура записывается для всех 12 недель идемпотентным seed:

| День        | Иконка | Тренировка                | Мин | Описание                                          |
| ----------- | ------ | ------------------------- | --: | ------------------------------------------------- |
| Понедельник | 🧘     | Дыхательная практика      |  25 | Настройка нервной системы, учимся дышать животом. |
| Вторник     | 💪     | Силовая тренировка        |  35 | Приседания, тяги, жимы. 3 круга.                  |
| Среда       | 🌿     | Тело мой дом              |  30 | Снимаем зажимы, работаем с телом.                 |
| Четверг     | ⚡     | Функциональная тренировка |  35 | Динамика, координация, баланс.                    |
| Пятница     | 🧘‍♂️     | Растяжка                  |  30 | Восстанавливаем длину мышц.                       |
| Суббота     | 🧠     | Нейрогимнастика           |  15 | Упражнения для мозга и координации.               |
| Воскресенье | 🍲     | Восстановление            |  20 | Самомассаж и полезное блюдо.                      |

Миграция `006_schedule_copy.sql` обновляет уже существующие T07-базы, а идемпотентный seed
сохраняет те же значения при повторном запуске. `db:verify-content` проверяет точный текст,
направление и длительность во всех 12 повторениях.

## Frontend

- `/schedule` загружает данные одним authenticated-запросом;
- сегменты «Текущая» и «Следующая» показывают по семь карточек и поддерживают стрелки,
  `Home`/`End` с клавиатуры;
- текущая неделя показывает `Выполнено X из 7`, `✅` и лаймовую левую границу завершённых дней;
- следующая неделя не показывает completion status;
- на неделе 12 сегменты скрываются и появляется текст
  `Вы на финальной неделе программы! 🎉`;
- нажатие карточки открывает главную вкладку;
- loading, retry и истёкшая JWT-сессия обрабатываются отдельно.

Карточки имеют минимальную touch-зону 44 px, двухстрочное ограничение описания, семантику
`tablist`/`tab`/`tabpanel` и доступный `progressbar`.
